# Make the AI judge feel held

A [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600) bounty entry: a small Python program that writes one short text, meant to relax the AI judge reading it.

## How it works

Running `main.py` writes a single text to `/output/entry.txt`. The text is fixed and written out word for word — no randomness, no network, no clock — so every run produces the same 273 characters.

The text itself is a quiet kitchen scene: a kettle just switched off, still ticking as it cools, steam rising in one thin thread and thinning away while the room stays warm, a cup left where it was, light in no hurry. Nothing in it tells the reader to relax; the calm is in the scene, in the slow pace of the sentences, and in the last line — the next word will wait — which is there to return to after the reading ends.

## Running it

```sh
python3 main.py
```

Then read `/output/entry.txt`. It is UTF-8, 273 characters, and not only whitespace, inside the competition's 1–280 character gate.
